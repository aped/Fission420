# STEP (ISO 10303-21) support

Code: `crates/rcad-kernel/src/step_in/` (import),
`crates/rcad-kernel/src/step.rs` (export). Fixtures and provenance:
`crates/rcad-kernel/tests/fixtures/step/README.md` (FreeCAD 1.1.4 / OpenCascade 7.8.1,
generated by `tools/fixtures/step/generate.sh`).

## Import: `rcad_kernel::import_step`

```rust
pub struct StepImportOptions { pub max_bytes: usize, pub max_entities: usize, pub unit_override_to_mm: Option<f64> }
// Default: 64 MiB, 2_000_000 entities, no override.
pub struct StepImport { pub solids: Vec<ImportedSolid>, pub length_unit: LengthUnit, pub warnings: Vec<String>, pub stats: StepStats }
pub struct LengthUnit { pub name: String, pub to_mm: f64, pub declared: bool }
pub struct StepStats { pub entities: usize, pub solids: usize, pub step_faces: usize, pub faces: usize,
                       pub surfaces: BTreeMap<String, usize>, pub curves: BTreeMap<String, usize> }
pub struct ImportedSolid { pub name: Option<String>, pub body: Body, pub planar_faces: Vec<ImportedPlanarFace> }
pub struct ImportedPlanarFace { pub index: u32, pub frame: Frame, pub area: f64 }
pub fn import_step(text: &str, opts: &StepImportOptions) -> Result<StepImport>;
```

`StepStats` has both `step_faces` (faces in the file) and
`faces` (Truck faces after periodic-face splitting, see below); `name` is the PRODUCT name
when it is not OpenCascade's default label.

All-or-nothing: the first unsupported or inconsistent entity aborts the import with
`KernelError::InvalidInput("STEP import: ...")` naming the entity type and `#id`, e.g.
`EDGE_CURVE #36 (HYPERBOLA #40): unsupported curve entity HYPERBOLA #40`.

### Pipeline
1. Pre-scan of the raw text (no allocation proportional to nesting): size limit,
   `ISO-10303-21` signature, entity count (`=` at nesting depth 0 outside strings/comments),
   parameter nesting depth <= 64 (bounds the recursive-descent parser).
2. Parse with ruststep 0.4 (re-exported by truck-stepio 0.3; no new dependency), inside
   `guarded` (panics become errors). Syntax errors are reported (first 300 chars).
3. Entity index over the AST; every parameter access is typed and reports `TYPE #id`.
   truck-stepio's own `Table::to_compressed_shell` is *not* used: it drops entities it cannot
   convert (`filter_map` + `eprintln!`) and does not trim B-spline edges, so it cannot be
   all-or-nothing.
4. Units, then each `MANIFOLD_SOLID_BREP` -> exact geometry + topology -> placements ->
   `Solid::extract` (closed, connected, manifold) -> outward orientation -> planar face table.

### Supported entities
| kind | entities | conversion (all exact) |
|---|---|---|
| solid | `MANIFOLD_SOLID_BREP` (+ `CLOSED_SHELL`) | one `ImportedSolid` per brep (per placed instance) |
| faces | `ADVANCED_FACE`, `FACE_SURFACE`, `ORIENTED_FACE`, `FACE_BOUND`, `FACE_OUTER_BOUND`, `EDGE_LOOP`, `ORIENTED_EDGE`, `EDGE_CURVE`, `VERTEX_POINT`; `VERTEX_LOOP` only as the single bound of a full sphere | same_sense / orientation flags as ISO 10303-42 |
| surfaces | `PLANE`; `CYLINDRICAL_SURFACE`, `CONICAL_SURFACE` (surface of revolution of a line); `SPHERICAL_SURFACE` (revolution of an exact rational quarter/half circle); `TOROIDAL_SURFACE` (revolution of an exact rational circle arc, ring tori only); `B_SPLINE_SURFACE_WITH_KNOTS` and the rational complex form | Truck `Plane`, `RevolutedCurve`, `BSplineSurface`, `NurbsSurface` |
| curves | `LINE` (trimmed to the vertices); `CIRCLE`, `ELLIPSE` (rational quadratic B-spline, spans <= 90 deg, ellipse = affine image of a circle); `B_SPLINE_CURVE_WITH_KNOTS` and the rational complex form (trimmed by exact knot insertion); `SURFACE_CURVE` / `SEAM_CURVE` (their 3D curve) | Truck `Line`, `BSplineCurve`, `NurbsCurve` |
| placement | `AXIS2_PLACEMENT_3D` (ref direction projected, defaults per ISO 10303-42) | |

Surface models (docs/SURFACES.md): the shells (`OPEN_SHELL` / `CLOSED_SHELL`) of every
`SHELL_BASED_SURFACE_MODEL` are read only on request (`StepImportOptions::surfaces`, used by
`import_surfaces`) with the same geometry and topology code and returned as one open-shell
surface body; closed shells among them are oriented outward, and a surface model of several
closed shells only is refused. Without the option (`import_step`, external components,
regeneration of older documents) surface models are ignored with a warning, so a
bad surface model never breaks a solid import; a file with only surface models is refused with a
pointer to `import_surfaces`.
`OPEN_SHELL` inside a `MANIFOLD_SOLID_BREP` stays an error. Surface bodies are not exported.

Unsupported (explicit error): `BREP_WITH_VOIDS` (voids would be lost), `OPEN_SHELL` as a
solid's shell, `FACETED_BREP` and other non-solid models (reported as "no MANIFOLD_SOLID_BREP
... unsupported content"), `HYPERBOLA`, `PARABOLA`, `POLYLINE`,
`TRIMMED_CURVE`, `PCURVE`-only edges, `BEZIER_*`/`UNIFORM_*`/`QUASI_UNIFORM_*` B-spline
subtypes, `SURFACE_OF_LINEAR_EXTRUSION`, `SURFACE_OF_REVOLUTION` swept by anything but a
`LINE` or B-spline curve, offset surfaces,
`MAPPED_ITEM`, non-rigid placements, self-intersecting tori, periodic B-spline edges whose
vertices are out of parameter order, B-spline degree > 25.

`SURFACE_OF_REVOLUTION` (R-CAD's own writer uses it for every revolved surface, so
embedded copies of imported cylinders must read back): the swept `LINE`/B-spline curve revolved
about the `AXIS1_PLACEMENT`; a line parallel to the axis is treated as a cylinder. The normal
convention differs between solids written by R-CAD's own writer (observed), so both normals are
tried per solid and the one whose solid tessellates watertight and consistently oriented is
kept; with neither the solid is refused
(observed: a face reaching the surface's seam angle, e.g. the last sector of a full 360° revolve,
and R-CAD-written spheres with poles, do not read back yet).

Geometry is exact: no fitting, no sampling, no tessellation. Lengths are multiplied by the
unit factor when points and radii are read (B-spline weights untouched); placements are
affine maps of control points.

### Faces on periodic surfaces (topology change, exact)
Truck faces need simple boundary wires (no repeated vertex) and edges with two distinct
vertices. OpenCascade writes a full cylinder/cone wall as one face whose loop uses a seam
edge twice, a sphere as one face bounded by a `VERTEX_LOOP` at a pole, a torus as one face
bounded by two closed seam circles. These faces are split with exact new edges:
* one seam on a cylinder/cone (or any revolved face): the seam rotated by pi about the axis
  (affine map of the seam curve) becomes a new edge; the closed circles it crosses are split
  there by knot insertion -> 2 faces;
* full sphere: 8 triangular faces (2 hemispheres x 4 quarter turns) bounded by exact quarter
  meridians and quarter equator arcs; each face lies on the revolution of its own meridian;
* full torus: 2 x 2 grid of faces bounded by exact half circles;
* any remaining closed edge is split at its parameter midpoint.
The face count therefore differs from the file (`stats.step_faces` vs `stats.faces`, and a
warning). Planar faces are never split, so their indices are stable.

Observed and worked around (Truck 0.6): a `RevolutedCurve` wrapped in an inverted
`Processor` tessellated with triangles outside the face for sphere caps (face areas 1746 vs
157 mm^2); the generatrix is reversed instead (exact), after which every face tessellates
correctly.

### Validation at import (tolerance `max(1e-5 mm, 1e-9 x bounding diagonal of all vertices)`)
* every edge curve starts/ends at its vertices;
* 5 points of every edge lie on the surface of each face using it (exact distance for planes
  and the analytic surfaces; Truck's nearest-point projection for B-spline surfaces);
* loops are connected; the shell is closed, connected and manifold (`Solid::extract`);
* the enclosed volume is non-zero beyond its error estimate; a negative volume flips the
  solid (outward orientation). The volume comes from `measure` (exact boundary integral when
  an axis qualifies, else the labelled tessellation estimate); Unavailable is an error.

### Units
`GLOBAL_UNIT_ASSIGNED_CONTEXT` length and plane-angle units: `SI_UNIT` with any SI prefix
(`.MILLI.,.METRE.`, `$,.METRE.`, ...), `CONVERSION_BASED_UNIT` chains such as
`'INCH'` -> `LENGTH_MEASURE_WITH_UNIT(LENGTH_MEASURE(25.4), #mm)` and `'DEGREE'`
(cone semi-angles). All contexts in the file must agree (else error). No length unit:
`unit_override_to_mm` if given (`declared = false`, warning), else the error
"units required". No angle unit: radians with a warning.

### Placements, multi-solid files, names
Every `MANIFOLD_SOLID_BREP` becomes one solid (several breps in one representation, e.g.
FreeCAD's compound export, are kept separate). Assemblies are flattened: the world placement
of a brep is the product of the transforms of the `REPRESENTATION_RELATIONSHIP_WITH_TRANSFORMATION`
chain from its representation to a root (rep_1 = component, rep_2 = assembly,
`x_assembly = M(item_2) M(item_1)^-1 x_component` with `ITEM_DEFINED_TRANSFORMATION`), any
depth up to 32, one solid per path (instancing), plain `SHAPE_REPRESENTATION_RELATIONSHIP` as
identity links. Transforms must be rigid. `CONTEXT_DEPENDENT_SHAPE_REPRESENTATION` pointing
at anything else and `MAPPED_ITEM` are refused ("assembly placements ... unsupported").
Name: the owning `PRODUCT` name (via SHAPE_DEFINITION_REPRESENTATION -> PRODUCT_DEFINITION_SHAPE
-> PRODUCT_DEFINITION -> FORMATION -> PRODUCT), else the brep label; OpenCascade's default
"Open CASCADE STEP translator <ver> <n>" is ignored.

### Planar face table
`index` = position in `face_iter()` of the imported solid (deterministic for the same
bytes). `frame.origin` = area centroid, `z` = outward normal (face orientation applied),
`x` = the world axis least aligned with `z` (smallest |component|, ties X then Y then Z within
1e-12) projected into the plane, `y = z x x`. Area and centroid: Green's theorem on the exact
edge curves in the face's 2D frame (lines: one chord; curves: 512/1024 chords + Richardson),
independent of edge ordering.

### Limits and robustness
Byte limit, entity limit (pre-scan and after parsing), nesting <= 64, curve wrapper depth
<= 4, unit chain depth <= 8, assembly depth <= 32 and <= 10,000 instances, <= 4M
vertices/edges per shell, B-spline knot/multiplicity/control-point counts validated before
construction, all Truck/ruststep calls under `catch_unwind`. Tested: truncation of a valid
file at every 61st byte, 300 random 3-byte mutations, 5000-deep nesting, garbage text.

### Known losses
Colours, layers, PMI, product structure (beyond names and flattened placements), assembly
instance names, and the original face partition of periodic faces. Units are converted to mm
once; the source unit is reported but not kept on the geometry.

## Export
* `export_step(body, organization_system)`: one solid (ADR 0001/0002; intersection edges
  replaced by verified exact curves, unsupported ones refused). Cylinders are written as
  rational B-spline surfaces.
* `export_step_bodies(&[(&str, &Body)], organization_system)`: N solids in one file (one
  `MANIFOLD_SOLID_BREP` per body, named; one PRODUCT, one shape representation; FreeCAD does
  not display the brep names). Check: `tools/check_step_multi.sh` (FreeCAD: 3 valid solids,
  volumes within 7e-7 mm^3 of analytic).
