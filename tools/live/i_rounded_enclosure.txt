# Run 6 (SESSION_6 acceptance 1): a rounded, labelled enclosure built from New
# through real pointer/keyboard input with general tools: parameters, a drawn
# and bound rectangle, extrusion, four solid fillets bound to corner_r, the
# cavity from the projected top face offset inward by the wall (associative),
# a lid projected from the bottom face on an offset plane, raised "B8" text
# with all glyph regions in one Join; then a length edit that the cavity, lid
# and text follow, an excessive radius refused, undo/redo, save/close/reopen
# and STEP export. Expected volumes: closed-form (rounded rectangle areas;
# glyph area of B8 at 12 mm from tests/rounded_enclosure.rs = 103.380146 mm²).
clickw New
wait_idle
typew New parameter name | length
typew New parameter expression | 100
clickw Add parameter
wait_idle
typew New parameter name | width
typew New parameter expression | 70
clickw Add parameter
wait_idle
typew New parameter name | height
typew New parameter expression | 30
clickw Add parameter
wait_idle
typew New parameter name | wall
typew New parameter expression | 2.4
clickw Add parameter
wait_idle
typew New parameter name | corner_r
typew New parameter expression | 6
clickw Add parameter
wait_idle
expect params.corner_r 6 0
clickw Parameters header
# Outline: corner rectangle from the origin, dimensioned, bound to length/width.
clickw New Sketch on XY
wait_idle
clickw 2-Point Rect
sclick 0.3 0.2
sclick 40 30
expect editing.entities 4
key d
sclick 20 0
type 100
key Return
key f
wait_idle
sclick 100 15
type 70
key Return
expect editing.status FullyConstrained
clickw Finish Sketch
wait_idle
clickw Sketch1
typew width (mm) | length
typew height (mm) | width
clickw Apply
wait_idle
clickw Extrude…
typew Extrude distance (mm) | 30
key Return
wait_idle
clickw Extrude1
typew distance (mm) | height
clickw Apply
wait_idle
expect volume 210000 0.01

clickw OK

key 3
key f
wait_idle
wclick 100 35 15

clickw Extrude1 side face (sketch entity 3)

clickw OK
wait_idle
expect last_reply.ok true
key 6
key f
wait_idle

clickw Fillet edge…

clickw Extrude1 side face (sketch entity 4)

clickw Apply
wait_idle

# inner region 27.6 deep (height - floor).

key f
wait_idle
wclick 50 35 30

wait_idle

wait_idle
